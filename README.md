# 寸心 · A Glimmer of Heart

> 谁言寸草心，报得三春晖 —— 长忧九十九的家长人生模拟
>
> 以家长视角进行的育儿人生模拟游戏（原型），目前包含**四章、从出生到幼儿园毕业**。

> 游戏内容、玩法机制与策略空间的完整说明见 **[DESIGN.md（游戏设计文档）](DESIGN.md)**；本文件聚焦技术架构与开发指南。

- **第一章 · 月子期**（第 0~27 天，按天推进）：出生、月子抉择、黄疸、夜醒风暴、产后情绪、满月酒
- **第二章 · 婴儿期**（第 28~75 周，按周推进）：产假结束孩子谁带（老人/托育/阿姨/全职四路线）、自费疫苗档位、翻身认生出牙辅食爬行等里程碑、第一声爸爸妈妈、二胎抉择、学步保护vs放手、断奶、周岁抓周
- **第三章 · 幼儿期**（第 76~99 月，按月推进）：terrible two、语言爆发、如厕训练、超市躺地、玩具保卫战、屏幕时间第一战、隔代溺爱、挑食、早教班三档、滑梯上的放手哲学、**第一次撒谎（撒谎链第一颗种子）**、入园准备、三岁生日+择园四档（公办摇号/普惠/民办/国际）
- **第四章 · 幼儿园**（第 100~135 月，按月推进）：公办摇号（30%落榜转普惠）、开学分离焦虑结算、第一兴趣班、**撒谎链第二次发芽（化石级种子的一次逆转窗口）**、同学矛盾、老师约谈、六一表演、幼小衔接三择、毕业典礼；学费按月结算（公办大班免保教费·2025新政）
- **第五章 · 小学**（第 136~195 月，按学期月推进，暑假折叠）：幼升小三择（对口/民办/学区房¥60万）、拼音关、作业战争、**成绩单签字（撒谎链第三次发芽——伪造签名）**、兴趣池（天赋显形）、二胎出生、家长会、三年级分水岭、近视（OK镜/框架/户外）、校园边界、手机之战、小升初结算（成绩公式：天赋×习惯×状态×择校）
- **第六章 · 初中**（第 196~225 月，按学期月推进）：**青春期**（初潮双视角/变声劈叉/身高冲刺性别分速/房门与敲门）、手机战争正面战场（合约 vs 没收）、初二物理分化（天赋文案）、**早恋苗头（撒谎链联动：诚实线他会说，隐瞒线他熟练否认）**、染发提案、朋友圈、体育中考（陪跑40秒）、**中考分流四档（重点/普高/职高专业匹配天赋/中专）**——职高线由天赋×赛道错配真实可达

本原型验证的核心设计（详见"设计支柱"）：锚点+模板双层事件、flag 收敛、延迟后果、随机体质、影响而非控制、变粒度时间轴（天→周→月）、阶段主题色。

## 怎么运行

- **玩**：双击 `index.html` 即可（无构建、无依赖，file:// 直接跑）。
- **事件编辑器**：双击 `editor.html`（游戏开局屏也有入口）。与游戏共用同一份数据与引擎，四大板块：
  - **校验报告**：死链（later 引用）、不可达（flag 被要求但从未设置 / careMode 不可达 / 窗口越界）、字段拼写（effects/conditions 未知键）、make 工厂在 mock 状态矩阵下的可执行性；点击条目跳转事件库
  - **事件库**：锚点/后续/模板/疾病全量浏览，按阶段过滤与搜索，详情含 `[Function]` 标记的 JSON，可一键复制
  - **Flag 收敛图**：每个 flag 的设置来源（收敛路径）、条件消费方、注册状态——收敛机制的可视化
  - **模拟看板**：浏览器内分批跑 N 局（不卡界面，可停止），锚点触发率/模板频率/flag 分布/育儿账本
- **模拟测试（命令行）**：`node test/smoke.js [局数]`（默认 2000）。批量随机通关并输出平衡报告。

## 事件数据结构

**锚点事件**（手写主线）：

```js
{
  id: 'a_yuezi_plan',
  kind: 'anchor', priority: 'main',   // main: 每天最多 1 个；side: 体检类
  day: [1, 3],                        // 日龄窗口（按截止日排序，窗口紧的优先）
  conditions: { careModeIs: null },   // 触发条件，缺省为无
  art: { pose, expr, outfit, scene }, // 组合立绘的四个图层 key
  text: '...',                        // 或 make(state) 动态生成
  make(state) { return { text, choices } },  // 可选：需要掷骰/读状态时用工厂
  choices: [{
    text: '顶级月子中心',
    cost: { money: 68000 },           // 仅展示用
    conditions: { moneyGte: 68000 },  // 不满足则置灰并提示原因
    effects: { money: -68000, mama: 15, careMode: 'center',
               setFlags: { '婆婆失落': '来源描述' } },
    result: '选择后的结果文案',
  }],
}
```

**effects 支持的字段**：`money / energy / marriage / inLaw / mama / face / security / nursingSkill / gasCount / visitorCount / overfed / nightWakeStreak / weightG / lengthCm / careMode / feedingMode / childName / setFlags / unsetFlags / log / later`。

**later（延迟后果）**：

```js
later: [{ afterDays: 2, chance: 0.5, eventId: 'follow_jaundice_worse', withFlags: {...}, preview: '发芽预告' }]
```

到期掷骰，通过则应用 effects / 注入后续事件。

**视角系统（爸爸/妈妈视角）**：世界与数值完全相同，变的是叙事视角。开局选择，默认妈妈视角。三种适配方式：

1. **条件文案变体**：`text` / `choice.text` / `choice.result` 允许写成数组，`when` 复用条件系统（含 `perspectiveIs`），不带 `when` 的放最后做兜底：

```js
text: [
  { when: { perspectiveIs: 'mama' }, text: '你还没出院……' },
  { text: '妻子还没出院……' },
]
```

2. **make 工厂**：需要整组换选项的事件（出生第一眼、产后情绪）在 `make(state)` 里按 `state.perspective` 分支，返回 `{}` 走默认文案。
3. **称谓槽**：`{spouse}`（老公/老婆）、`{spouse_name}`、`{spouse_pron}`（他/她）由 resolveText 按视角替换；模板家族在 make 时自行读 `state.perspective`（如妈妈视角下"丈母娘"变"你妈"）。

**模板家族**：`{ id, weight, minDay, perDayMax, cooldown, canTrigger(state), make(state) }`，make 时根据隐藏状态（气质/体质/喂养方式）生成结果矩阵——夜哭家族是范例：原因（饿/胀气/受惊/求安抚）对玩家隐藏，只能靠文案线索猜；同一个"任由哭"选项，天使型和高需求型的代价差 6 点安全感。

## 核心机制速览

| 机制 | 实现位置 | 说明 |
|---|---|---|
| 变粒度时间轴 | config.STAGES(dayWeight) + engine.stageOf | 全局统一 tick，各阶段粒度不同（月子按天×1、婴儿期按周×7、幼儿/幼儿园按月×30）；生长/工资/周结算全部按真实年龄天数（ageDays）对齐 |
| 撒谎链 | a_first_lie（两岁半）→ a_second_lie（四岁半）→ a_sign_report（小学）| 三次发芽：牛奶→花瓶→**伪造签名**；前两次各有一次逆转窗口，第三次是"最后一次"；小学毕业时撒谎链状态回响在成绩单上 |
| 阶段主题色 | style.css `body[data-stage]` + renderTopbar | 月子暖橘 → 婴儿期暖黄 → … 九阶段预配置，切章自动换装 |
| 托育路线 | a_back_to_work + CARE_WEEKLY_COST | 老人(免费但隔代冲突)/托育(¥1000周,交叉感染×2.2)/阿姨(¥1500周)/全职(收入×0.55) |
| 隔代冲突 | tpl_grandparent | 追喂/穿太多/把尿三大经典战场，绑老人带娃模式 |
| 消耗品档位 | config.CONSUMABLES + engine 周结算 | 尿不湿/奶粉三档（经济¥65/主流¥105/高端¥195每周，奶粉¥160/260/400），每周自动扣费；**经济款尿不湿红臀风险翻数倍**（illness 池联动） |
| 性别化内容 | templates.js 购物池/亲友语录 | 女宝推衣服（头饰/纱裙/母女装）、男宝推玩具（健身架/床铃/牙胶），权重更高；语录含"招商/建设银行"式话语——只呈现不评判 |
| 负债危机线 | a_debt 锚点（money ≤ -100） | 找父母周转（接济 flag）/信用卡分期（利息 later 结算）/紧缩降档（强制换经济尿不湿）三条路，各有代价 |
| 婚姻危机线 | a_cold_war(≤55,可每6天重复) → a_marriage_redline(≤46) | 阶梯式升级；红线事件"离婚两个字第一次出现"种下`月子仇`或`悬崖边拉回`——离婚分支的种子章（见下方评估） |
| 育儿账本 | effects.spendKind + 结算屏 | 每笔开销按 衣服/玩具/医疗/照护/酒席/教育/日常消耗 记账，周岁结算分类展示 |
| 视角系统 | config/state/events + 文案变体 | 爸爸/妈妈视角：数值同世界，叙事双版本（详见上文） |
| 影响而非控制 | templates.js 夜哭矩阵 | 孩子体质/气质随机且隐藏，通过行为反馈显形 |
| flag 收敛 | flags.js + conditions | 不同路径 set 同一 flag（先入为主记来源），下游读状态不读路径 |
| 延迟后果 | effects.later | 黄疸观察/捂汗/购物后悔都是 N 天后兑现 |
| 变粒度时间 | engine.advanceDay | 本章按天；引擎用 tick，后续章节按周/月配置 |
| 随机体质 | state.js | 五档不可选；只影响路径难易，不影响结局好坏 |
| 生长曲线 | growth.js | WHO 简化百分位；喂养方式/体质/过度喂养影响日增重 |
| 疾病池 | illness.js | 概率 = 基础率 × 体质系数 × 环境（亲友探视累积提升发烧风险） |
| 精力经济 | engine.finishDay | 剩余=喘口气回血，透支=关系和状态记账 |
| 组合立绘 | render.js artBlock | 体态×表情×服装×场景，目前是占位块+emoji，换真图只改这一处 |

## 扩展指南

- **加事件**：锚点加进 `anchors.js`（主线节点），日常流水写成新模板家族加进 `templates.js` 的 `TEMPLATES` 数组即可被调度器自动纳入。
- **加疾病**：`illness.js` 的 `ILLNESSES` 数组加一项（canTrigger + dailyProb + make），恶化走 `FOLLOWUP_EVENTS` + later。
- **加阶段**：`state.js` 的 child/family 结构已预留跨章节字段；把 anchors 的 day 窗口换成"周数"即可扩展 0-3 岁章（引擎的 tick 粒度改为按周配置）。新阶段在 `config.STAGES` 注册 + `style.css` 加一段 `body[data-stage]` 配色即可获得专属主题色。
- **加性别化内容**：购物池条目带 `gender: 'girl'|'boy'|null`；亲友语录支持 `{ t, g }` 条目按孩子性别过滤；`kind` 字段决定记账分类。
- **配真图**：只改 `render.js` 的 `artBlock()`——按 pose/expr/outfit/scene 四层拼合，资产量 400~600 张可覆盖组合爆炸。

## 已评估待实现的设计

### 离婚分支：结论是"加，但分三步走"

1. **本章（月子期）只种种子，不真离**。已实现婚姻危机阶梯：争吵(≤55) → 红线之夜(≤30)，红线事件里"离婚"两个字第一次出现，四种应对分别种下 `月子仇` 或 `悬崖边拉回`。月子期真离婚既不符合数据也不符合叙事节奏——但"月子之仇"是真实高频的婚姻创伤叙事，种子必须在这里埋。
2. **后续章节用多因子触发，不用单一阈值**：婚姻值只是输入之一，还要叠加 争吵计数、婆媳状态、经济压力（卡债/接济 flag）、异地/加班因子。进入"危机态"后给 **三次干预机会**（深谈/婚姻咨询/分居冷静期），每次都是一次选择——离婚是玩家一路选择走到的地方，不是随机惩罚。
3. **离婚不是 fail state，是另一条路**：单亲困难模式（收入砍半、精力更紧）、抚养权谈判、老人深度介入、若干年后"复婚/再婚"事件。孩子的性格会真实地被这条路改写——这才是这套系统值得做的原因。

### 成绩系统：波动性与"成绩单签字"（小学/初中章）

成绩不是智力的直接读数，设计为 `成绩 = 能力 × 状态 × 环境` 的动态值：

- **能力**（智力/学习习惯）只是底盘；**状态**（睡眠、心情、亲子信任、师生关系）是乘数；**环境**（换学校、二胎分宠、家庭争吵）直接震荡。所以"小学成绩好、初中突然掉下来"是系统的自然产出：小升初环境突变 × 青春期状态乘数下滑。
- **成绩单让父母签字**是核心锚点事件：签+批评（压力↑信任↓）/ 签+奖励（动机外化）/ 帮孩子改分数再签（`隐瞒` flag——撒谎链的入口之一）/ 只签不说（孩子自己解读）。签字方式与前期教育风格共同决定孩子接下来"报喜还是报忧"。

### 价格档位基准（已进 config.FUTURE_TIERS，来自 2025 公开收费数据）

幼儿园四档：公办 ~¥600/月（2025 秋季起大班免保教费）、普惠民办 ~¥1500、中端民办 ~¥4500、国际双语 ~¥15000。民办园在民办园就读的还可参照公办标准减免——做幼儿园章时"公办摇号"本身就是事件。

## 设计红线

1. 不预设正确答案——每个选择都有真实代价
2. 后果用叙事呈现，不用扣分弹窗
3. 数值藏在幕后——玩家记住的应该是故事和遗憾
